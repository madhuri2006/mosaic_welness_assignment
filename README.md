# LilChoice 🌿

**Good choices start with understanding.**

Little Joys Clarity is a customer-focused web platform developed as part of the **Mosaic Wellness Fellowship – Part 2**. It helps customers understand product ingredients, nutritional information, product claims, and suitability considerations to make informed purchasing decisions.

🌐 **Live Demo:** [https://cute-caramel-02599a.netlify.app/](https://cute-caramel-02599a.netlify.app/)

## 🛍️ Products Covered

- Mom Multivitamin Gummies
- Nutrimix Nutrition Powder for Kids
- Chocolate Hazelnut Spread

## ✨ Key Features

- **Product Explorer:** Explore the three selected products and their details.
- **Ingredient Detective:** Understand product ingredients through simple explanations.
- **Nutrition & Claim Decoder:** Simplifies nutritional information and explains product claims, including sugar-related claims.
- **Suitability Guide:** Highlights relevant precautions and product considerations.
- **Price Breakdown:** Helps customers understand product pricing and value.
- **Customer Insights:** Connects findings from five customer interviews with the proposed solution.
- **Customer Feedback:** Provides a space for customers to share feedback and experiences.
- **Little Joys Club:** Demonstrates a customer loyalty and rewards concept.
- **Ask Little Joys:** Chatbot preview for product-related questions.
- **Light/Dark Mode:** Allows users to switch between themes.

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/madhuri2006/mosaic_wellness_assignment.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

No backend setup is required for the current prototype.

## 📝 Prototype Notes

- The chatbot is a preview and is not connected to a live AI backend.
- The loyalty programme and cart are demonstration features, not connected to real rewards, payments, or order processing.
- Product information and prices are reference content and may change.
- Suitability information is educational and does not replace professional medical advice.
